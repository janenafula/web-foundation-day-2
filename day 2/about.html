About QuickNotes

QuickNotes is a simple application for creating and organising notes quickly.

How to Use QuickNotes

Type your note into the note field and select the Add Note button. Your note can then be viewed in your notes list.

Features

  • Quick note creation
  • Simple and clean interface
  • Easy note organisation
  • Keyboard shortcuts

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save a note
Esc Clear the current action
